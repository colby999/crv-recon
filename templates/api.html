CRV recon API

Free, no auth, JSON everywhere. Every link below is live — click to run it against the current data. Agents: /llms.txt is the machine-readable map.

Programs

  • GET /api/programs — full catalog. Filters: ?platform=, ?tier=S, ?vdp=&show=, ?q= (matches target identities too), ?sort=newest|bounty|reports|name
  • GET /api/programs/<id>/targets — one program's scope, scored

Changes & targets

  • GET /api/changes — latest target/program events. ?kind=target_added|target_removed|…
  • GET /tags — tag inventory (HTML); GET /api/tags (JSON)

CVEs

  • GET /api/cves?program_id=<id> — scanner-attributed rows + one page of corpus hits, newest first. ?page=N&per_page=M (per_page 1–100)

Scans

  • POST /api/scan — {"program_id": N, "identity": "owner/repo", "mode": "light|full|sniper|cves", "manual": true} — queues the external scanner; manual scans skip the scope check (your tool, your call)
  • GET /api/scans?program_id=<id> — scan queue + results

Status & ops

  • GET /api/status — program/scrape counters
  • GET /api/refresh/status — is a refresh running
  • POST /api/refresh — kick live scrapers + corpus pulls (409 if one is running)
  • GET /health — liveness

Exports

  • GET /export.txt — plain-text program list; ?format=targets appends scope identities

HTML pages (/ etc.) are for humans; JSON endpoints are stable — build on them.
